# Secrets inventory - who holds what

Golden rule: **no secret ever needs to leave your hands** (and never paste them
into a chat with an AI assistant). Only non-secret facts do: hostname, server
IP, OS choice.

| Secret | Generated by | Lives in | Goes in `.env`? |
|---|---|---|---|
| Vault **master password** | You, in the Bitwarden client at account creation | Your head + offline emergency sheet | ❌ never (it's client-side only) |
| **ADMIN_TOKEN** | You - run the command below (locally or on the server) | `.env` as argon2 PHC string | ✅ |
| **SMTP user/app-password** | Your email provider | `.env` | ✅ (only if you enable email verification) |
| **rclone crypt passwords** (backup encryption) | You, when creating the `crypt` remote - pick strong ones, keep an offline copy | `rclone.conf` (obscured, laptop + server) + offline sheet | ❌ - without them the backups are unrecoverable |
| **Google OAuth token** (backup remote) | `rclone authorize` browser flow | `rclone.conf` (laptop + server) | ❌ |
| **SSH private key** | Yours: `~/.ssh/<your-key>` (content in `.deploy.env` via `$(cat ...)`, content in CI secrets) | `~/.ssh/` / CI secret store | ❌ |
| **Deploy connection** | You - fill `.deploy.env` | laptop only (never uploaded to server) | ❌ |
| **JWT_SECRET** (Workers) | `workers/deploy.sh` auto-generates it | `.workers.env` (mode 600, local/CI only) | ❌ (Worker runtime secret) |
| **Cloudflare API token** (Workers CI/CD) | You - CF dashboard → API Tokens → "Edit Cloudflare Workers" | CI secret store / `.workers.env` | ❌ (direct env value, never a path) |
| **Tunnel credentials** (`cert.pem`, `<id>.json`) | `tunnel-init.sh` - you click the login URL once | server `~/.cloudflared` + `/opt/passvault/cloudflared/` (mode 600) | ❌ |
| **GitHub Actions secrets** | You - repo → Settings → Secrets → Actions | GitHub (encrypted) | ❌ (used as env values, never a path) |
| **2FA TOTP seed** | Bitwarden client when enabling 2FA | Vault + printed offline copy | ❌ |

## Google Drive backup - where everything lives

| Thing | Location |
|---|---|
| The backups | Google Drive → **My Drive → folder `vaultwarden`** → folder + file with **scrambled names** (that's the client-side encryption working - nothing readable reaches Google) |
| The crypt passwords | Chosen by you when creating the `crypt` remote - keep an **offline copy** (paper / password manager); restore is impossible without them |
| The rclone config (OAuth token) | `~/.config/rclone/rclone.conf` on laptop **and** server (mode 600) |
| The schedule | systemd `passvault-backup.timer` on the server - daily 04:00 UTC (`systemctl list-timers \| grep passvault`) |
| Restore | `rclone copy gdrive-crypt:vaultwarden/ ./restore` → extract the tar → put `db.sqlite3` into a scratch container's `/data` (RUNBOOK §7.6) |

Note: rclone's shared Google client_id is being retired during 2026 - create
your own OAuth client (Google Cloud Console → OAuth client, *Desktop app*) and
run `rclone config update gdrive client_id=… client_secret=…`, then
`rclone authorize drive` again, before the cutoff.

## Generate ADMIN_TOKEN

On the server (Docker, after §3 of RUNBOOK):

```bash
docker run --rm -it vaultwarden/server:latest /vaultwarden hash
```

Or on any machine with the `argon2` package (`sudo apt install argon2`):

```bash
echo -n 'YOUR-ADMIN-PASSWORD' | argon2 "$(openssl rand -base64 32)" -e -id -k 65540 -t 3 -p 1
```

Paste the `$argon2id$...` output into `.env` **single-quoted** (it contains
`$` signs): `ADMIN_TOKEN='$argon2id$v=19$...'`.
The admin password you typed is used nowhere else - it only unlocks `/admin`.

## SMTP (optional but recommended)

Any provider works. Common setup (Gmail, needs 2FA on the Google account):

```
SMTP_HOST=smtp.gmail.com
SMTP_PORT=587
SMTP_SECURITY=starttls
SMTP_FROM=you@gmail.com
SMTP_USERNAME=you@gmail.com
SMTP_PASSWORD=<16-char App Password from myaccount.google.com/apppasswords>
```

Then set `SIGNUPS_VERIFY=true` in `.env` so unknown signups must confirm by
email.

## Offline copies to keep (paper or USB in a drawer)

1. Vault master password
2. rclone crypt password
3. One printed 2FA recovery code / TOTP seed for the vault account
